# Fictional workbooks

Copies of the three AA workbooks for testing. **All names and figures are fictional.**

| File | Copy of |
|---|---|
| `AA_Master_Schedule_FICTIONAL.xlsx` | Staffing & capacity planner |
| `AA_Project_Tracker_FICTIONAL.xlsx` | 2026 master schedule (project tracker) |
| `AA_Projections_Business_FICTIONAL.xlsx` | Business projections |

What was replaced (2026-10-13):

- Project numbers and names: one fictional number and name per project, the same across all three files (year prefix and order kept).
- Clients, staff names and initials.
- Billable rates, mixed rate and salaries: new fictional values.
- Fees, contract values, billing, operating costs: scaled by a random factor per project or cost line (relations within a row kept), including amounts typed inside formulas.
- Tracker free-text notes: replaced with generic milestones.
- Document author and SharePoint metadata removed.

Unchanged: every formula, hours, dates, phases, statuses, percentages, headcount.
Excel recalculated all totals from the fictional inputs.

The real workbooks stay outside git (`Excell/` is ignored). Swap them in locally when the repo is private.
